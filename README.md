# Transportation Solver

## Step 1: Get the Code

Open **Command Prompt (CMD)**, go to your Desktop, and run:

```bash
git clone https://github.com/SindhuGV199/Transportation-Solver.git
cd Transportation-Solver
```

## Step 2: Run the Backend (IntelliJ IDEA)

1. Open IntelliJ IDEA.
2. Click **File → Open** and select the folder `transportation-model`.
3. Wait for Maven to finish loading the dependencies.
4. Open `TransportationModelApplication.java`.
5. Click the green **Run** button.
6. Keep the backend running while using the application.

## Step 3: Run the Frontend (VS Code)

1. Open VS Code.
2. Click **File → Open Folder** and select `major_project_frontend/transportation-frontend`.
3. Open the terminal using **Ctrl + `**.
4. Run the following commands:

```bash
npm install
npm run dev
```

5. Open the local URL displayed in the terminal, usually:

```text
http://localhost:5173
```

## Prerequisites

- Java Development Kit (JDK)
- IntelliJ IDEA
- Node.js and npm
- Git
